## 关键反例及结果

| 反例 | 结果 |
| --- | --- |
| 数据专用 eSIM 没有号码、ICCID/EID、线路 | 允许保留最小条目，不造假数据 |
| 两端用不同关系 ID 新增当前付款卡 | relation_slot_conflict；不按 ID 不同就放行 |
| 金额用浮点/指数/负零、未知币种或超出精度 | 只读诊断，不转换或四舍五入 |
| 一端改金额、另一端改核实依据 | 数值/币种/时间/来源/可信程度为同一个 String 原子组，不拆拼 |
| 新字段或复合未知子项、未来 schema、重复 JSON/字段 Key | 原文及保护属性不变；未知/重复明确拒绝自动编辑 |
| 已知卡号被写为未保护 | 显示仍需显式揭示，并返回保护缺失诊断，不静默修复保护位 |
| 本地时间在 DST 缺失/重复区间 | 缺失拒绝；重复必须显式 fold；无时区不猜 |
| 0001/9999 年本地时区转换越界 | unsupported_time_range，不抛未处理 OverflowError |
| 旧 parentEntryUuid 与新父关系不一致 | legacy_parent_conflict；不拆分旧混合凭据，不改密码/KPEX |
| 旧父关系自指/目标类型不符/目标缺失 | 自指和类型不符只读；缺失保留 warning，不找同名替代 |
| 滚动依据属于另一规则，或完成已撤销 | 错规则拒绝；无效/撤销/缺失依据不作为已确认期限 |
| 点击通知、录入时间代替发生时间 | 不接受通知点击为 completed；occurredAt 与 recordedAt 分别保存 |

K068 没有实现三方合并、patch、日期推进、实际调度或写库；测试检查输入与不变量，不把“原子组定义”冒充事务引擎。

## 独立复核

独立子代理 review_security_contract 先只读审查 K001/T15/T16 与领域文档，提出跨 ID 槽位、事实来源原子组、未知数据、旧混合凭据、保护策略、日期精度、无 ICCID eSIM 等 7 个核心问题及迁移/浏览器令牌措辞问题。已落实到字典、测试和对应文档。

随后对新代码做有限独立源码复核，定位极端年份、旧别名单独引用和输入形状边界。最后两项发现是 typed 非 login 条目使用旧父别名仍会被判 valid，以及只有未知 keex 前缀时绕过只读策略；均已修正并加入上述 63 项主会话实测。无 marker 的旧 parent 别名与非 keex 插件字段仍保留兼容。

子代理的远程执行调用阻塞后被中止，没有取得测试结果；不能称为独立实测通过。本轮独立证据是源码与设计复核，测试由主会话执行。模型复核不宣称人工或第三方安全审计；K001/K002 已登记的人工门槛保留。
