## 1. 代码与已执行链路

| 位置 | 实际实现 |
| --- | --- |
| `tests/nsh_candidate/rust/src/controls.rs` | Mutex/Condvar 交付屏障；私有 nsh_core MemoryClipboard 的版本、所有权、受控单调时钟与到期策略 |
| `rust/src/lib.rs` 的 VaultSession | inactive 状态本身拒绝新授权；撤销 epoch、释放 vault/编辑状态、清自己的剪贴板；active 只改变活动状态，不恢复 vault。后台任务交付前再检查 epoch |
| `VaultPanel.tsx` | 真实订阅 lifecycle/wakeCount；inactive/background 清 UI 并通知 Rust，wake 锁库；cleanup 锁库并释放测试屏障，不让销毁后在途任务永久等待；只显示白名单错误码 |
| `SecurityApp.tsx`、`Lifecycle.test.tsx` | 共用同一个 VaultPanel，不复制安全逻辑；额外控件只在实验 surface 显示。父组件保留非敏感审计码以观察子组件销毁后的回调 |
| `security_check.py` | 检查原始完整 trace 的私有哨兵缺席、公开 TSX 输入负控制出现、固定错误码路径到达及运行结束；检查输出目录 JSON 元数据，含旧 receipt |

NSH v0.6.1 的 nsh-testing/src/module.rs 提供 setLifecycle/wake，driver.rs 将其注入同一引擎环境。本轮通过实际 API 注入触发 VaultPanel effect，再调用 Rust setActive/lock；保留旧 ticket 直接请求字段被 Rust 拒绝，而不是只断言遮罩。回 active 没有重新解锁。Rust 单测另验证 inactive 时 beginUnlock 得到的票据不能授权，复制也拒绝。

## 2. 屏障与剪贴板验收范围

- 解锁、字段读取、分页、保存序列化、核心到内存剪贴板复制，分别在后台运算完成、结果交付前进入真实 Condvar 屏障。测试等待明确的“已进入”握手，再锁库、释放；五类旧请求均返回 STALE_SESSION，UI/剪贴板无旧交付。没有随机 sleep。
- 同一读取屏障在不撤权时正常交付，排除“总是拒绝”的假通过。销毁组件时 cleanup 撤权并释放屏障，父组件观察 STALE_SESSION；重挂仍锁定。
- 保存屏障位于磁盘写入前，因此该特定反例拒绝后不进入写入；**不能推导已经开始的 OS 写入可取消，也不终止 KDF。** 普通保存仍有原 K091 的密文副本可能落盘限制。
- MemoryClipboard 由 Rust 私有持有，不接系统剪贴板、不经 JS 传递被复制字段。测试旧定时版本不能清新版本，1 秒到期清自己内容，锁库清自己内容，用户后来复制不同内容或相同文本均改变所有权并保留。版本不只比较字符串。
- 时钟由受限实验 API 显式前进；不是已接入 OS 后台计时器。系统剪贴板原子所有权、历史/跨设备同步、原生 Input 自带复制粘贴均未验收。

## 3. 重要未解决项：TSX 输入的原始 trace 确实会泄漏

**不能宣称“敏感输入不进 trace”整体通过。** Rust 私有哨兵经核心错误与 MemoryClipboard 路径不进入 JS、固定错误码、原始 trace、普通 Storage 或输出 JSON；但这不能覆盖 TSX Input 路径。

公开 L0 负控制在同一个 masked 主密码 Input 键入标记，再锁库。原始 trace 同时包含 type 步骤参数和 InputValue 的完整标记。已排除“只有测试标签回显”：实际 InputValue 挂载负载也有完整文本。固定源码 nsh-testing/src/trace.rs 的 item_lines 对 InputValue 走 Debug 输出，print_items 原样输出；VaultPanel 的 masked 属性没有提供 trace 脱敏保证。锁库后清 signal 不会抹去已写日志。

本轮不修改上游，也不通过事后脱敏日志冒充原始日志无泄漏。负控制作为应检出的现存风险保留；`security_check.py` 的 pass **仅表示私有 Rust 路径检查与负控制检测成功，不表示 TSX 输入安全。** 它不扫描/证明所有堆副本、OS 缓存或安全擦除，不把代码常量/构建产物当加密存储。

解除该阻塞需要后续明确选择并实际验证原生安全输入到受限 Rust 的路径，或上游/经审查 runner 的输入 trace 脱敏及禁止发行调试入口；不能用本机 fake 输入代替四端 IME、读屏、预览及内存生命周期结果。
