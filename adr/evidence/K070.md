# K070 证据：浏览器 KDBX 运行时与 Flutter 绑定方案

日期：2026-10-31。状态 **DOING**。依赖 K003、K069 还没 DONE，这是合成预实验：只用公开合成库，写入闸门不开。复现方法见 [tests/wasm_core](../../tests/wasm_core/README.md) 和 [tests/flutter_bridge](../../tests/flutter_bridge/README.md)。

## 结论先说

**建议的联合方案：Dart/Flutter 负责界面和平台，Rust 负责 KDBX。一份 Rust 核心，一个 Dart 接口，原生走 FFI，Web 走 Worker + WASM。这条路本机实测走通了。** 最终选型仍由 K009 裁决。

| 候选 | 能进浏览器吗 | 保留性（同一批 21 个用例） | 许可证 | 判断 |
| --- | --- | --- | --- | --- |
| **keepass-rs 0.15.3 + K003 补丁，走 WASM** | 能，五个浏览器都通过 | 9 个无差异，12 个明确拒绝，0 个静默出错 | MIT | **推荐** |
| **同一份 Rust，Dart → FFI** | 不适用（原生路径） | 和上一行逐项相同 | MIT | **推荐** |

| kpasslib 1.1.2 | **不能**：无条件依赖 `dart:ffi`，dart2js 和 dart2wasm 都编译失败 | 19 个有差异，1 个写出 oracle 读不了的文件 | MIT | 不作 writer |
| ManyKee（keepass-rs 分支 + Dart 接口） | **没运行**，见下 | **没运行** | MIT | 结构最接近，值得实测 |

## 绑定方式

| 方案 | Web | 原生 | 判断 |
| --- | --- | --- | --- |
| **自己写薄壳：`dart:ffi` + `dart:js_interop`** | 实测通过 | 桌面 Dart 实测通过，手机没测 | **推荐**：接口只有几个函数，代码量小 |
| [flutter_rust_bridge](https://cjycode.com/flutter_rust_bridge/manual/miscellaneous/web-cross-origin) 2.13 | 文档要求 COOP/COEP 跨源隔离；不隔离时所有函数同步跑在主线程 | 成熟 | 只看了文档，没实测。Web 不用：KDF 不能卡界面，跨源隔离又可能影响弹窗授权 |
| [native_toolchain_rust](https://pub.dev/packages/native_toolchain_rust) 1.0.7（Dart build hook） | 平台列表里没有 Web | Android、iOS、桌面 | K004 打包动态库时优先实测，只解决构建，不解决接口 |
| [Rinf](https://pub.dev/packages/rinf) 8.11 | 页面写支持，隔离要求没写明 | 支持 | 只看了文档。维护者正在找接手的人，消息模型对这几个函数也偏重 |

自己写薄壳不是因为社区库不好，而是我们的接口很小，而且 Web 上的约束（必须 Worker、不能跨源隔离）正好和通用方案的默认做法相反。接口变大时要重新评估。

## 浏览器实测（官方 Safari 27.0、Chrome 154.0.8037、Edge 156.0.4314；Firefox 157.0 和 WebKit 27.2 是 Playwright 版）

环境：Apple M1 Pro，macOS 26.6.2，32 GiB。**下面每行五个浏览器结果相同，** 耗时取范围，都是单次。

| 项目 | 结果 |
| --- | --- |
| 读全部 61 份登记样本（3.1/4.0/4.1） | 全部打开，条目数和 oracle 一致，都没被误判成有未知内容 |
| 5 份样本读改写（到 10000 条目） | oracle 全文比较只有这次编辑；和原生补丁库输出语义相同；KeePassXC 能打开 |
| 错误密码 | 普通错误，Worker 还能继续用 |
| 未知内容 | 能读不能存；带受保护值的拒绝打开，和原生一致 |
| 种子、IV、盐 | 两次保存都不同（浏览器里的随机数） |
| 取消 | KDF 跑到一半结束 Worker，主线程不卡，新 Worker 里没有旧状态 |
| 主线程 | KDF 期间定时器最长间隔 13–33 毫秒 |
| CSP | 只多放开 `'wasm-unsafe-eval'`，不需要 `'unsafe-eval'`；不放开时确实编译不了 |
| WASM 大小 | 1.1 MiB，gzip 后 359 KiB |

| KDF（读或写一次） | 浏览器 WASM | 原生 | 倍数 |
| --- | --- | --- | --- |
| AES-KDF 100 万轮 | 677–717 毫秒 | 约 30 毫秒（补丁库） | **约 23 倍** |
| AES-KDF 600 万轮 | 4.0–4.3 秒 | 没测 | |
| Argon2id 64 MiB，2 次 | 124–136 毫秒 | 80 毫秒（argon2-cffi） | 约 1.6 倍 |
| Argon2id 64 MiB，3 次，并行 2 | 180–214 毫秒 | 64 毫秒 | 约 3 倍，WASM 只能单线程 |
| Argon2id 256 MiB，2 次 | 485–611 毫秒 | 351 毫秒 | 约 1.5 倍 |
| Argon2id 1 GiB，2 次 | 2.0–2.3 秒 | 1.6 秒 | 约 1.4 倍 |
| Argon2id 1920 MiB，1 次 | 1.9–2.6 秒 | 没测 | |
| Argon2id 2048 MiB | **崩溃**（RuntimeError，1 毫秒内） | | wasm32 单次分配不能超过 2 GiB |
| Argon2id 3072 MiB 及以上 | 普通错误 `Memory cost is too large` | | |

原生对照用的库不同（AES-KDF 是补丁库，Argon2 是 C 实现），倍数只看量级。

10000 条目大样本：解锁 1.2–1.4 秒，保存 1.4–1.5 秒，WASM 内存 149 MiB。

**这对产品意味着：**

- **Argon2 没问题，AES-KDF 是短板。** 用 AES-KDF 且轮数很高的老库在浏览器里会慢很多，WASM 用不上 AES 硬件指令。不能调低 KDF（ADR-0007），只能提前提示。
- **内存上限不到 2 GiB，而且这只是 Mac 上的数字。** 手机浏览器的限制更严，没测。解锁前要先读文件头的参数，超出能力就明确拒绝，不要等到崩溃。这一步还没实现。
- **WASM 内存只增不减。** 跑过 1 GiB KDF 的 Worker 会一直占着 1 GiB，Argon2 内存也不保证清零。所以锁库必须结束 Worker，不能只是清变量；已写进 `VaultCore` 的约定。主密码经过 JS 字符串，也无法清零。

## Flutter 联合实验

| 项目 | 结果 |
| --- | --- |
| Dart → FFI → Rust，21 个用例 | 和直接调 Rust **逐项相同** |
| Flutter Web（JS 编译）→ Worker → WASM | Chrome、Firefox、WebKit、官方 Safari 都通过，写出的库通过同一套核对 |
| Flutter Web（`--wasm` 编译） | Chrome 真的用了 Wasm；Firefox、WebKit 回退到 JS，功能不受影响；官方 Safari 没跑这种编译 |
| 第三方请求 | `--no-web-resources-cdn` 后为 0（Chrome、Firefox、WebKit；Safari 没有手段统计） |
| 严格 CSP | `--csp` 构建，不放开内联样式也能渲染，截图看到页面（Chrome、WebKit 看了截图），但有 1 条内联样式违规提示；`<base href>` 要求 `base-uri 'self'` |
| 界面帧间隔 | 最长 41–216 毫秒，都小于一次 AES-KDF 的 700 毫秒，说明 KDF 没有卡住界面 |
| 体积 | 构建目录约 40 MiB；页面实际下载约 8–15 MiB（未压缩，几次差别大，只看量级） |

## 其它候选的实测

**kdbx.dart 2.5.0**（`node drive-dart.mjs`，Chrome、Firefox、WebKit 相同）：

| 编译方式 | AES-KDF | Argon2d | Argon2id |
| --- | --- | --- | --- |

**kpasslib 1.1.2**（`compare_candidates.py`，原生运行）：

- 好的一面：3.1、4.0、4.1 都按原版本写回；受保护值按文档顺序解密，字段顺序错位也能解对；保存结果 KeePassXC 能打开。
- 差异来源：改写 `Generator`；去掉分组的 `EnableAutoType`、`EnableSearching`；去掉历史里的 `QualityCheck`；附件引用属性变化。
- **条目和历史里的未知元素被悄悄删掉；未知元素带受保护值时，1 字节用例写出了 oracle 读不了的文件，8 字节用例因 UTF-8 错误才碰巧拒绝。** 这和 keepass-rs 打补丁前是同一类问题。
- 进浏览器要改依赖：`dart:ffi` 要改成条件导入。
