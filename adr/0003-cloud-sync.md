# ADR-0003：WebDAV / OneDrive 密文同步

日期：2026-10-12。状态：**方案与测试契约；没有连接真实云账号**。本轮将 OneDrive 从“后续增强”提升到与 WebDAV 同期的 P3 目标。引用 Rxx 见 [调研](research/mobile-sync-2026-10-12.md)。

## 1. 一个密码库，一个双向同步绑定

KDBX 保持唯一权威凭据格式。主程序维护本地可用文件、加密祖先快照与有限加密备份；网络 provider 不解密凭据。每个绑定记录 provider 类型、远端身份、对象标识、已确认版本及对应本地 generation；没有主密码或字段明文。

同一库首版只允许一个活跃双向源。WebDAV 与 OneDrive 可分别服务不同库；多个目的地的单向备份以后单独设计。不能同时让“iOS 文件 App 的 OneDrive 文件”和“Graph 直连 OneDrive”竞争写同一对象。切换同步方式前停旧任务、确认版本、保留备份并重新绑定，不直接叠加。

| 用户入口 | 授权与访问 | 一致性负责人 |
| --- | --- | --- |
| WebDAV 直连 | 用户指定 HTTPS 服务及受限账户 | keex 条件写入与冲突处理 |
| OneDrive 直连 | Microsoft 公共客户端 OAuth / Graph | keex 验证过的提交协议 |
| 从“文件”打开 | 系统文件提供者与文件授权 | OS provider 的可见能力 + keex 本地协调；不宣称等价 Graph CAS |

用户不需要部署 keex 账号服务器；OneDrive 集成仍需开发者注册 Microsoft 应用和 redirect URI，这不是把客户端 secret 填进 App。

## 2. 统一接口与状态

拟定 `connect / inspectCapabilities / stat / downloadVersion / createOnly / replaceIfVersion / cancel / disconnect`。请求只携带已完成加密的对象与版本条件，返回类型化结果：`Committed(version)`、`Conflict`、`AuthRequired`、`Missing`、`UnsupportedPrecondition`、`RetryLater`、`UnknownOutcome`。

能力报告不能只写“支持 WebDAV/Graph”；需包含强版本标识、读取版本与内容一致性、创建防覆盖、最终替换条件、续传、文件访问授权和后台限制。没通过的能力为 unknown/unsupported，不用服务品牌推断。

```text
仅本地 → 本机已保存/待同步 → 核对远端 → 上传中 → 远端确认
                                  ├→ 下载完成/等待解锁 → 合并 → 再核对提交
                                  ├→ 冲突待处理（保留双方）
                                  ├→ 需重新授权（不妨碍本地开库）
                                  └→ 结果不明/失败（核对后重试）
```

一个上传任务绑定不可变密文快照和 generation。上传期间用户又修改本机，旧版本成功不能把最新版本标成已同步。超时不等于远端失败；先查已提交内容/版本，避免无条件重放。

## 3. WebDAV

配置页包含服务地址、用户名、应用专用密码/凭据、目标路径、测试结果和隐私说明；认证信息在系统安全存储，不能仅存进尚未下载成功的同一库造成启动依赖循环。

测试用用户明确选择的测试对象，不修改真实目标：发现能力 → 受限目录检查 → 下载指定版本 → 验证条件创建/替换。通常读取使用 GET，目录/属性使用受限 Depth 的 PROPFIND；ETag 与条件语义以服务器实际行为验证。[R13]

既有对象在已知强版本上以 If-Match 提交；首次创建需要防覆盖条件。弱 ETag、缺失版本、忽略条件的服务不能走自动覆盖路径；LOCK 可作辅助，不能代替正确性证明。收到 412 保留本地及远端，不自动重试覆盖；错误 HTML 登录页不能当作 KDBX。

限制响应大小、XML 深度/实体、目录深度、路径编码与跨源跳转；禁止 HTTP 降级、静默忽略证书错误、把认证头转发到任意跳转目标。断网/401/403/429/507 各有不同恢复操作，不统一“重试直到成功”。

## 4. OneDrive：公共客户端、最小权限

主路径采用 MSAL 或经审查的原生 OAuth 适配，**授权码 + PKCE + 系统浏览器/受支持 broker**；验证 state/回调及账号上下文，token 放系统安全存储。不要嵌入 client secret，不把 Device Code 作为默认手机登录体验。只有主应用请求交互授权，凭据扩展不打开 Microsoft 登录。[R12]

默认评估应用专用目录 `Files.ReadWrite.AppFolder`，通过 `/me/drive/special/approot` 或 drive-ID 路径定位。读取用户现有任意目录是独立模式，明确额外权限，不把选中一个文件说成只获得这个文件的授权。个人与工作/学校账号、管理员限制分别测试。[R09]

注意官方 app-folder 说明与部分上传端点通用权限表的覆盖范围不完全一致。必须实验验证“所选 scope + 账号类型 + 精确端点”；失败时给出原因并重新评审，不悄悄升级到 `Files.ReadWrite.All`。不同端发布保持一致的应用身份配置，避免进入不同 app folder。

远端持久绑定使用 driveId/itemId 等稳定对象身份，路径只作展示/初始选择；文件改名、移走、被用户删除和账号切换都要求重新核对，不误操作同名的新文件。

### 不能把能上传当作不会覆盖

简单 `PUT .../content` 文档未列出 If-Match 请求契约；不能仅给 SDK 添个 header 就认为有完整 CAS 保证。Upload Session 明确提供创建时版本条件，但会话创建时检查通过不自动证明最终提交时仍检查同一基线。[R10,R11]

官方 createUploadSession 文档另有一条**带条件的最终提交**路径：向条目路径发 PUT，请求体带 `@microsoft.graph.sourceUrl`（上传会话 URL），文档写明这次调用可照常使用 `if-match`（Example 7）。`deferCommit: true` 的完成方式按账号区分：个人版用的正是这种 PUT；Business/SharePoint 是向 uploadUrl 发零长度 POST，文档没写它能带条件（Example 4）。

优先验证个人版“deferCommit + 带 If-Match 的 sourceUrl 提交”；Business 的零长度 POST 单独测，测不出最终条件就按无可靠 CAS 处理。两种完成方式分别实现，不混用。关键反例必须执行：A 基于 v1 创建上传会话 → B 写入 v2 → A 完成上传。只有 A 最终拒绝旧基线或进入无覆盖冲突结果，才能开放自动替换。

尚不能证明最终条件替换安全时：保留原远端，上传可独立打开的新版本/冲突 KDBX，进入显式解决流程，或暂停上传；不以先 GET 再无条件 PUT 的方式伪装安全。辅助元数据不能成为唯有 keex 才能打开的另一种权威密码库格式。

分片上传、续传、会话过期、最终确认按 Graph 协议实现。uploadUrl 本身是临时授权材料：不得写日志、截图、普通索引或对话；对预授权上传 URL 不附带 Graph Bearer token。分片进度/202 不等于已提交。[R10]

## 5. 合并、备份和后台

共享核心执行祖先/本地/远端三方合并。条目时间戳只是用户信息，不是胜负规则；删除与修改、组移动、历史、二进制引用、主密钥变更、OTP计数和 Passkey 材料分别处理。

Passkey 的 credentialId、RP、userHandle、私钥及有关密码学元数据形成不可拆拼的凭据集合；同一凭据身份出现不同私钥是安全冲突，禁止自动签名或逐字段拼接。HOTP 并发取码不以 max(counter) 就声称无损。没有可靠祖先保留双方，不猜测。

加密快照保留数量/容量/恢复路径可配置；同步删除不自动删掉所有备份。密钥轮换后旧备份仍可能用旧密钥打开，需要告知，不能承诺撤销远端已有副本。日志只留事件码、脱敏对象和传输大小，文件名/RP 等潜在隐私不默认外发。

iOS 主程序前台主动同步，后台利用系统允许的传输机会；Android 使用可恢复任务调度。两者都不能承诺被系统终止后按固定分钟可靠运行。锁定时只传输已存在的密文，不解密合并；扩展注册本地提交后可标待同步，不把成功取决于网络。[R19]

## 6. 必测场景

WebDAV 正确/缺失/忽略条件服务；OneDrive 个人/工作账号的 scope 与最终 CAS；两台手机与桌面参考客户端（如 KeePassXC，不是 keex 桌面版）并发；上传成功但超时；锁库途中；主程序与扩展并发注册；本机新 generation；断网/令牌撤销/配额满；用户在云端改名/删除；Files 与直连重复绑定。所有测试使用独立合成库与测试目录。

安全降级是一项产品能力，不是异常吞掉：界面必须区分“仅保存到本机”“等待解锁”“需要重新授权”“远端已变化”“当前服务无法保证自动覆盖安全”。
