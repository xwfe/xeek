## 2. 一级信息架构

| 固定导航 | 内容 | 不属于本页 |
| --- | --- | --- |
| 密码 | 网站/应用登录、API 凭据、安全备注；收藏、分组、标签；创建/编辑中的生成器 | 独立全局“生成器”导航 |
| 验证 | 动态口令 TOTP/HOTP、通行密钥、恢复码、SSH 密钥；分段筛选；关联原条目 | 把 Passkey 统称为二次验证码；把硬件私钥说成已导入 |
| 证件 | 身份证、护照、驾照、自定义证件；附件、到期提醒 | 宣称照片等同官方电子证件/身份认证 |
| 银行 | 借记卡、信用卡、银行账户；卡号遮罩、到期日、持卡人、备注 | 支付、转账、余额聚合、支付牌照等新业务 |
| 设置 | 密码库、同步/备份、自动填充、生物解锁、SSH 代理、安全检查、外观语言、导入导出 | 默认强制服务器节点或订阅 |

同一登录条目可带 TOTP/恢复码/SSH 字段；“密码”和“验证”展示同一个 UUID 的不同视图，不复制秘密。允许没有登录密码的独立验证条目。通行密钥可替代密码，不是都属于二次验证。多个通行密钥保留多个凭据身份，不按域名去重覆盖。

## 3. 原稿需要纠正的地方

| 原稿情况 | 修订决策 |
| --- | --- |
| 四项底栏：密码库、生成器、安全审计、节点设置 | 固定为用户指定的五项；工具进入上下文操作或设置 |
| `Docker Vaultwarden 主节点`、节点在线、100% 同步 | 删除强制后端语义。显示当前 `.kdbx`、本地保存状态和真实同步状态；未配置时显示“未配置同步” |
| `Argon2id + AES-256-GCM` 当作 KDBX 套件 | 详情根据文件头显示。KDBX 内建 AES 为 AES-256-CBC，4.x 另有头部与分块 HMAC 验证（3.1 没有 HMAC），不能写成 GCM；Argon2id 是 KDF，不是每个条目的一种加密算法 |
| `主密码` 出现在 GitHub 凭据详情 | 改为“密码”；“主密码”专指解锁密码库的密钥材料 |
| 固定内存 64MB/t=3/p=4、“自定义熵池”、破解需数百亿年 | 删除默认宣传。KDF 经设备校准，生成器用系统 CSPRNG；强度是估计而不是保证 |
| `剪贴板将在 30s 后粉碎`、复制前已成功的提示 | 改为实际复制成功后提示“稍后尝试清除本次复制内容”；不承诺移除系统历史/其他应用副本 |
| 六位 PIN 直接解锁、错五次擦除、紧急救援恢复密钥 | 不作默认路径。先实现主密码/密钥文件；快速解锁需设备安全密钥包裹；不能自动删除库或暗示万能恢复 |
| “一键安全修复”“95% 极高防御”“公开黑产库命中” | 改为有来源、时间和方法的具体检查结果；改网站密码需用户去网站操作；默认只进行本地检查 |
| YubiKey 已连接/Passkey 已授权/生物识别成功静态写死 | 显示能力状态；外部安全密钥凭据不可当成可导出的软件通行密钥 |
| 恢复码前后重复明文、生成历史明文、离线共享二维码 | 默认遮罩且按需显示；生成历史默认不持久化；不在首版做明文分享或假二维码密钥交换 |
| “军工级”“端到端本地孤岛”“TLS 1.3 即端到端” | 删除营销式安全术语；密码库文件加密和网络传输保护分别说明 |

技术依据见 [RESEARCH.md](../RESEARCH.md) 的 S01、S05、S06、S08、S09。

## 4. 视觉与布局

保留原稿黑曜石底色、翡翠绿强调和验证码紫色的方向，但减少发光、重复安全徽章及占屏的大分数。深色背景 `#0f131c`、卡片 `#181b25`、主文字 `#e6eaf2`、强调 `#4edea3`；浅色使用对应语义变量，不用单纯反色。

中文使用系统字体栈（苹方、微软雅黑、Noto Sans CJK、系统无衬线），不强制下载英文展示字体。代码、卡号、验证码用系统等宽字体与等宽数字。常规正文 14–16，标题 24–32，触控目标至少 44×44 逻辑像素；原生移动实现以 48dp 为常规目标。

`<720` 使用底部五导航与单列列表，详情作为全屏层；`720–1099` 使用同顺序侧栏、单列内容与详情层；`≥1100` 使用侧栏加列表/详情双栏。导航始终有图标和文字；适配底部安全区与键盘，不让新增按钮盖住列表。Flutter 最终断点按实际可用宽度而非设备品牌判断。

高频复制放在详情里，不把每张列表卡塞满危险操作。默认列表仅显示标题、必要账号提示和类型；密码/恢复码/完整证件号不出现在列表。动态口令页可直观显示演示码，真实产品仍受锁定、屏幕共享/隐私模式控制。

## 5. 关键流程与状态

- 首次启动：创建/打开 KDBX → 主密码与可选密钥文件 → 库验证 → 首页；同步配置在用户需要时进行。无网络同样可用。
- 新建：所在分类预选模板 → 填写字段 → 校验 → 原子保存 → 显示“已保存到本机”；只有远端确认提交后才显示“已同步”。原型仅展示流程说明，不假装保存。
- 验证：按类型筛选 → 查看所属账户/域名 → TOTP 复制、恢复码使用标记、通行密钥系统调用、SSH 授权各走独立操作。
- 锁定：关闭敏感弹窗/撤销授权/清理会话 → 锁屏；生物解锁未开通时给出原因。不能用视觉遮罩替代真实锁定。
- 错误/空状态：无条目、无搜索结果、库损坏、密码错误、只读库、权限撤销、同步冲突、外部修改、备份失败、系统能力不支持都必须有可恢复路径。
- 全局搜索必须能找到其他分类；搜索结果带类别和“打开条目”。只索引已解锁库的必要字段，默认不搜索密码值。不存在搜索时的自动跨库解锁。
- 键盘：搜索快捷键、Escape 关闭详情/弹窗、可见焦点、键盘遍历；语义标签与读屏不要自动朗读秘密。

## 6. 中文术语表

| 对象 | 默认文案 |
| --- | --- |
| Vault / Database | 密码库 |
| Master password / Entry password | 主密码 / 密码 |
| Passkey | 通行密钥；说明处可写“通行密钥（Passkey）” |
| TOTP / HOTP | 动态口令（TOTP）/ 计数口令（HOTP） |
| Recovery codes | 恢复码，不称“密码库万能恢复密钥” |
| SSH Agent | SSH 代理；高级说明保留 SSH Agent |
| Autofill / Backup / Sync | 自动填充 / 备份 / 同步 |
| Unavailable / Not configured / Not checked | 当前平台不支持 / 尚未配置 / 尚未检查 |

品牌、URL、文件名、用户输入不翻译。Flutter 所有系统文案来自 `zh_CN.arb`；后续外语通过完整词条提供，不能散落硬编码导致混语。
